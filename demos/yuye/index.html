小程序不是一个“大而全”的项目，而是分期上线

一期先做企业介绍、产品资料、说明书、手册、视频文章、咨询和后台；后续再逐步增加经销商、订货、培训、AI 问答等业务能力。

① 拍照识病 → 疑似初诊 → 转技术员
② 免疫程序助手 → 品种 / 日龄 / 规格 → 生成方案
③ 扫瓶身码 → 正品验证 → 批号 / 效期 → 服务入口
④ AI 答疑 → 产品 / 疫病 / 免疫问题 → 人工转接
